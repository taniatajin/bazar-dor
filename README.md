# 🛒 বাজার দর (BazarDor)

বাংলাদেশের নিত্যপ্রয়োজনীয় পণ্যের দাম এক নজরে দেখার একটি Price Tracking ওয়েবসাইট।
চাল, ডাল, তেল, সবজি, মাছ, মাংস, ডিম-দুধ ও মসলার আজকের দাম, দাম বাড়া-কমার তথ্য
এবং বিভিন্ন বাজারের তুলনা এক জায়গায়।

🔗 **Live:** <bazar-dor-psi-one.vercel.app>

## Technologies Used

- Next.js (App Router) + TypeScript
- Tailwind CSS + DaisyUI
- BetterAuth (Email/Password, Google, GitHub)
- MongoDB Atlas
- React Hot Toast
- Lucide React

## Key Features

1. **Live Price Ticker:** infinite scrolling strip showing every product's price and ▲/▼ change
2. **Home Dashboard:** top 6 price risers, top 6 fallers and the full product list, in Bengali digits
3. **Category Pages:** filter by category with Bengali-aware numeric sorting (low to high / high to low)
4. **Product Details (Protected):** min, max and average price plus a market-by-market price table
5. **Authentication:** sign up and sign in with email/password, Google or GitHub using BetterAuth
6. **Profile Management:** view profile, sign out, and update your name
7. **Loading and Feedback:** skeleton loaders, toast notifications and a friendly 404 page
8. **Fully Responsive:** works on mobile, tablet and desktop
